# دفاع الدبابات v4 — 8 مراحل · 6 لغات
برمجة وتصميم: محمد العمري 730215825

## ما الجديد في v4
- 8 مراحل (4 جديدة) بمسارات وأعداء أصعب تدريجياً، مع أفضل نتيجة لكل مرحلة.
- موسيقى حماسية متواصلة (قائمة / معركة / زعيم) ومؤثرات صوتية واقعية للأسلحة والانفجارات، مع شريط تحكم بالصوت.
- دبابات وأبراج وقاعدة بتصميم جديد (جنزير متحرك، مدفع رباعي دوّار، منصة صواريخ، ملف تسلا، وميض إطلاق).
- آثار انفجار على الأرض، ظلال سحب، أيقونات مرسومة بدل الإيموجي.
- شاشة بداية، قائمة إيقاف مؤقت، إعدادات، زر «الموجة التالية»، وزر الرجوع في أندرويد.

## الطريقة 1: تشغيل فوري (بدون APK)
1. ارفع مجلد `www` على أي استضافة HTTPS (GitHub Pages / Netlify).
2. افتح الرابط في Chrome على الأندرويد ← ⋮ ← «تثبيت التطبيق».

## الطريقة 2: ملف APK
```
npm install
npm run android      # ينشئ مشروع أندرويد ويضبطه (أفقي + ملء الشاشة) ويفتح Android Studio
```
ثم Build ← Build APK(s). يتطلب Node.js و Android Studio.

## تجربة محلية
افتح `www/index.html` في Chrome.
